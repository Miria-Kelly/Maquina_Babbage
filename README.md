# Maquina_Babbage

Esse é um projeto do primeiro período do curso de ciência da computação.
O projeto é uma simulação da máquina analítica criada por Charles Babbage na década de 1830.

COMO USAR
Existe o arquivo "cartao.in" que simula o cartao perfurado onde X é 1 e O é 0, nele vão ser colocadas as informações para a realizaçao das operações.
Após colocar as informaões no aquivo "cartao.in" é só executar o arquivo "maquina.py" o "cartao.in" será lido e o resultado sairá no arquivo "cartão.out"
