# Maquina_Babbage

Esse é um projeto do primeiro período do curso de ciência da computação.
O projeto é uma simulação da máquina de Babagge, onde existe o aquivo "cartao.in" que simula o cartao perfurado onde X é 1 e O é 0, para a realização de operações matemáticas igual a máquina analítica criada por Charles Babbage na década de 1830.
